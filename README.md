# 梦想相册 iOS

原生 SwiftUI App（iOS / iPadOS 17 起，兼容 Mac Catalyst）：整理手机照片、管理系统相册，将精选图片保存为独立的梦想画册。视觉目标见 [最终选定设计](Design/selected-dark-photo-album.png)。

## 使用流程

- **照片**：按日期倒序浏览、月份和截图筛选、多选、全屏及缩放预览；右上角“整理”进入本轮或继续上次整理。
- **整理**：左滑标记待删、右滑留在相册。下方文字操作与左右方向键作用相同；撤销支持 Command-Z。加载失败时可重试，未加载成功时不能滑动判断。
- **待删清单**：标记不会删除原图，可逐张取消或清空；明确确认后才提交 PhotoKit 系统删除请求。取消或失败保留待处理项。Live Photo 的删除包括动态内容。
- **分组**：读写普通系统相册，创建、重命名、添加、移出照片；长按分组打开管理菜单。智能相册仅浏览，共享相册不在首版编辑范围。移出分组、删除分组均保留原图。
- **梦想画册**：从照片或分组中选择图片，保存独立优化副本后新建或加入已有画册；导入支持进度、失败重试和取消。后续删除手机原图不影响画册。长按画册可重命名、归档、删除，拖动可调整顺序。
- **我的**：保留主题、语言、归档等设置，增加权限、整理进度和待删清单入口。

原有成长记录、心情、里程碑、归档、桌面组件、拍照选图及 App iCloud 备份继续使用。默认首页改为手机照片，旧梦想数据与图片路径无需迁移。首版仅整理图片，Live Photo 使用静态预览，不包含视频和 AI 分类。

## 数据与权限

- `PhotoLibraryService` 为可替换服务接口；`SystemPhotoLibraryService` 负责 PhotoKit 读写、变化通知和可取消图片请求。
- `PhotoLibraryStore` 管理轻量元数据与权限；`PhotoReviewSession` 单独保存本机整理状态、撤销历史与待删标识，绝不加入画册云备份。
- 图片仅按可见尺寸请求，邻近预取限制在 19 个资源。大图与网格使用不同尺寸；离屏取消请求并释放图片。导入解码及写入在后台执行。
- 有限授权只展示获准资源，可管理可访问照片、本 App 创建的相册；其他相册需完整授权。撤销权限不会清空本机待删清单。
- 普通系统相册的跨设备同步由系统 iCloud 照片负责；梦想画册副本沿用既有 App iCloud 文档备份。画册副本经过优化，不是原始文件备份。

## 开发与验证

使用 Xcode 打开 `DreamAlbum/DreamAlbum.xcodeproj`，共享 Scheme 为 `DreamAlbum`，包含单元测试与界面测试。

```sh
xcodebuild -project DreamAlbum/DreamAlbum.xcodeproj -scheme DreamAlbum \
  -destination 'generic/platform=iOS Simulator' build CODE_SIGNING_ALLOWED=NO

xcodebuild -project DreamAlbum/DreamAlbum.xcodeproj -scheme DreamAlbum \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -only-testing:DreamAlbumTests test CODE_SIGNING_ALLOWED=NO

xcodebuild -project DreamAlbum/DreamAlbum.xcodeproj -scheme DreamAlbum \
  -destination 'platform=macOS,variant=Mac Catalyst,arch=arm64' \
  build CODE_SIGNING_ALLOWED=NO ONLY_ACTIVE_ARCH=YES
```

界面测试需要先为**测试模拟器**准备至少两张图片，授权照片完整访问。测试会在该模拟器创建系统测试相册与梦想画册，验证滑动判断、撤销、取消待删、系统分组写入和独立副本导入；不会实际删除手机原图。权限弹窗因操作系统版本差异可能需在测试前手动处理。

视觉验证见 `design-qa.md`；验证范围和真机验收清单见 `VALIDATION.md`。本次开发不发布 App Store。

### 2026-10-24 操作体验优化

全 App 使用统一深色背景，“我的”采用原生设置列表。照片页保持固定网格，点击“选择”后可横向滑动连续多选、双指滑动多选、全选或取消全选；也可长按照片直接进入选择。顶部显示已选数量，选中照片以缩进、遮罩与勾选标记区分。Mac / 外接键盘支持 Cmd-A 全选与 Escape 退出选择。大图预览支持系统捏合缩放、双击缩放及放大后拖动。

### 2026-10-26 待删入口与最近照片（构建 8）

首页标题下新增带数量的“待删”入口，全部照片上方也可直接打开清单；多选底栏用“待删”直接标记选中的图片，省去“更多”菜单。分组内选择照片后，“分组”菜单可添加或移出照片。整理页移除左右判断按钮和重复提醒，照片区域扩大；保留滑动、辅助功能操作、左右方向键、撤销与底部待删入口。

今天没有照片时显示最近 7 个自然日的照片与截图。如果图库更早，则以最近有照片的日期结束该 7 天范围；首页标明实际日期范围及数量。当天出现新图片后恢复今日照片；主动选择往日日期仍只展示那一天，日期未知图片仍可在全部照片查看。

可编辑分组提供“删除分组（保留照片）”和“删除分组及 N 张原图”。后者在同一次 PhotoKit 事务中删除分组内的图片原件与分组，图片在其他相册中的关联也会消失，梦想画册独立副本保留；不处理视频。系统拒绝、取消或失败时保留分组和照片。App 不追加确认弹窗，PhotoKit 的系统授权仍保留。有限授权下仅清理成功事务返回的资源标识，不用有限快照清空其他整理记录。

待删清单在系统删除成功后自动关闭并返回上一页；取消、失败或没有可删除项目时继续保留页面和待删状态。

整理完当前范围后自动回到照片首页，包括从全部照片、分组或“我的”进入的整理；待删标记和判断记录保留，不再停留在完成页。

全部照片中的大图预览支持左滑待删、右滑保留并进入下一张；放大时拖动只平移照片。分组与画册导入使用完整页面，加入分组支持收起键盘与滚动，避免窄屏裁切。

### 2026-10-27 待整理首页与提醒（构建 11）

首页现在自动选择最近一个尚未整理完成的日期，只展示未整理的照片和截图。当天完成或没有图片时，跳过完成日期，继续往前找；有日期的图片都处理完后再显示日期未知图片。新拍的照片优先出现。首页采用紧凑的分类卡片、三张缩略图预览、右上角全部照片、日期与待删入口，以及沿用上一版的底部进度栏（圆环、状态、日期和右侧继续整理）。全部完成才显示空任务状态，不再展示已完成分类。
