# 梦想相册 iOS

原生 SwiftUI App（iOS / iPadOS 17 起，兼容 Mac Catalyst）：整理手机照片、管理系统相册、制作拼图，将精选图片保存为独立的梦想画册。默认使用原生银灰主题，可在设置中选择雾蓝晨光或蓝紫珍珠；当前视觉记录见 [design-qa.md](design-qa.md)。

## 使用流程

- **照片**：首页展示最近尚未整理完的日期，隐藏空分类，完成后接着处理更早日期。日历可查看每天数量和进度、左右滑动切月、重新整理指定日期。“全部照片”提供月份与截图筛选、多选、全屏及缩放预览。
- **整理**：左滑标记待删、右滑保留，支持辅助功能操作与左右方向键；撤销支持 Command-Z。点击查看原图，双指或双击缩放；原比例下可下滑关闭。加载失败时可重试，未加载成功时不能滑动判断。
- **待删清单**：标记不会删除原图；点击删除直接交给 PhotoKit 系统确认，成功后关闭清单，取消或失败保留待处理项。逐张取消待删会让照片回到未整理范围，并在当前清单提供查看入口。Live Photo 的删除包括动态内容。
- **分组**：按 PhotoKit 能力创建、重命名、添加、移出及删除普通相册；长按或右侧菜单打开管理操作。空分组直接删除；非空分组可选择保留照片或同时删除原图。系统/只读分组支持浏览和整理其中照片，可在筛选中隐藏不可编辑分组。
- **梦想画册**：从照片或分组中选择图片，保存独立优化副本后新建或加入已有画册；导入支持进度、失败重试和取消。后续删除手机原图不影响画册。长按画册可重命名、归档、删除，拖动可调整顺序。
- **我的**：集中管理照片、分组、待删、梦想画册、归档和本机拼图；提供主题、语言、权限与提醒设置。整理提醒默认关闭，开启后默认每天 22:00，可自定义时间。

原有成长记录、心情、里程碑、归档、桌面组件、拍照选图及 App iCloud 备份继续使用，旧梦想数据与图片路径无需迁移。当前仅整理图片；Live Photo 可长按播放，动态资源不可用时仍可查看照片。不包含视频整理和 AI 分类。

## 拼图（构建 23）

从分组操作菜单或分组详情数量行进入“制作拼图”，选择类型后按顺序选图；分组多选工具栏的“拼图”会带入已有选择。空分组不可制作，选图限定当前分组的可访问照片；数量不适合目标类型时需明确调整，不会自动丢弃已选照片。

| 类型 | 数量 | 编辑能力 |
|---|---:|---|
| 宫格拼图 | 2–9 张 | 带照片预览的均衡及主图模板，无缺格；长按拖放或点选交换，独立裁切支持填满与完整显示 |
| 长图拼接 | 2–20 张 | 纵向或横向拼接，默认保留完整内容；调整顺序、手动裁边和间距 |
| 对比拼图 | 2–4 张 | 左右、上下、四格布局；之前/之后、自定义标签和可选日期 |
| 梦想海报 | 1–9 张 | 目标、旅行、成长模板；主图与小图、标题、日期和简短文字 |
| 自由拼贴 | 1–20 张 | 拖动、缩放、旋转、重叠；添加文字、背景色、中心对齐参考线、图层排序与锁定 |

宫格选完照片直接显示画布，底部固定“模板、比例、样式、照片”，工具面板不遮挡预览。单击照片提供裁切、替换、交换、移除；长按拖动交换，拖出画布取消；双击进入裁切，支持拖动、双指缩放和缩放滑块。“完整显示”保留全部内容，“填满”允许调整裁切。取消裁切不改动草稿，完成后记作一步撤销。两张提供左右、上下模板，三至九张提供六种均衡及主图组合。增减照片后自动采用适合当前数量的均衡模板，可撤销；旧草稿保留原排版，只有主动选择新模板才切换。文字、图层锁定、边框和类型切换位于“更多设置”。

非长图支持 1:1、3:4、4:3、9:16 和 16:9。其他类型沿用照片编辑工具和图层面板。一次完整拖动或滑块调整记作一步撤销，当前会话保留最多 30 步；Command-Z 撤销，Shift-Command-Z 重做。iPad 宽屏显示画布与右侧工具栏，宫格模板以两列展示；Mac Catalyst 支持鼠标操作和键盘快捷键。界面沿用当前主题，支持中英文。

“我的 → 我的拼图”管理本机草稿，可继续编辑、重命名、复制和删除。制作时先保存素材独立副本，再创建草稿；排版自动保存，退出或进入后台时落盘。删除手机原图或系统分组后，已有草稿仍可编辑。草稿不会同步到其他设备；删除草稿会清理其素材，不影响已导出的图片或梦想画册中的副本。

导出先生成成图，再选择“保存到照片”“加入梦想画册”或“分享”，草稿继续保留。默认 JPEG，可选 PNG；普通拼图长边可选 2048px 或 4096px，默认 2048px。纵向长图宽 1440px，横向长图高 1440px；长边超过 16000px 时显示页数并分段输出。生成过程显示进度，可取消、失败后重试；重新生成失败不会替换先前成功生成的结果。加入新建或已有梦想画册时先保存完整成图，再更新画册路径，避免经过普通导入的 2200px 压缩流程。

`CollageDocument` 独立版本化保存布局、素材相对路径、裁切、文字和图层；`CollageStore` 管理本机目录与原子写入；`CollageRenderer` 共用预览和导出布局，预览使用缩略图，导出在后台按图片或长图区域绘制。`PhotoLibraryService.saveGeneratedImages` 负责系统照片保存。新功能不改变 `Dream.imagePaths` 或既有 iCloud 备份格式，加入画册的成图继续参与原有同步。草稿不与系统分组建立自动增删关系，不新增付费限制；不包含截图自动去重、AI 排版、抠图或贴纸商城。

## 数据与权限

- `PhotoLibraryService` 为可替换服务接口；`SystemPhotoLibraryService` 负责 PhotoKit 读写、变化通知和可取消图片请求。
- `PhotoLibraryStore` 管理轻量元数据与权限；`PhotoReviewSession` 单独保存本机整理状态、撤销历史与待删标识，绝不加入画册云备份。
- 图片仅按可见尺寸请求，邻近预取限制在 19 个资源。大图与网格使用不同尺寸；离屏取消请求并释放图片。导入解码及写入在后台执行。
- 有限授权只展示获准资源，可管理可访问照片、本 App 创建的相册；其他相册需完整授权。撤销权限不会清空本机待删清单。
- 普通系统相册的跨设备同步由系统 iCloud 照片负责；梦想画册副本沿用既有 App iCloud 文档备份。画册副本经过优化，不是原始文件备份。

## 开发与验证

使用 Xcode 打开 `DreamAlbum/DreamAlbum.xcodeproj`，共享 Scheme 为 `DreamAlbum`，包含单元测试与界面测试。

```sh
xcodebuild -project DreamAlbum/DreamAlbum.xcodeproj -scheme DreamAlbum \
  -destination 'generic/platform=iOS Simulator' build CODE_SIGNING_ALLOWED=NO

xcodebuild -project DreamAlbum/DreamAlbum.xcodeproj -scheme DreamAlbum \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -only-testing:DreamAlbumTests test CODE_SIGNING_ALLOWED=NO

xcodebuild -project DreamAlbum/DreamAlbum.xcodeproj -scheme DreamAlbum \
  -destination 'platform=macOS,variant=Mac Catalyst,arch=arm64' \
  build CODE_SIGNING_ALLOWED=NO ONLY_ACTIVE_ARCH=YES
```

真实 PhotoKit 界面测试需要先为**测试模拟器**准备至少两张图片，并授权照片完整访问；会在模拟器创建测试相册与梦想画册。隔离服务测试使用 Debug 启动参数 `-dailyInboxFixture`；拼图界面测试另用 `-resetCollageFixture` 清理专属的 `CollageUITestDrafts` 目录，不操作常规草稿目录或用户原图。模拟服务覆盖失败与取消流程，不能替代真机权限、iCloud 下载和照片库写入验收。权限弹窗因系统版本差异可能需要预先处理。

视觉验证见 `design-qa.md`；验证范围和真机验收清单见 `VALIDATION.md`。本次开发不发布 App Store。

### 2026-10-24 操作体验优化

全 App 使用统一深色背景，“我的”采用原生设置列表。照片页保持固定网格，点击“选择”后可横向滑动连续多选、双指滑动多选、全选或取消全选；也可长按照片直接进入选择。顶部显示已选数量，选中照片以缩进、遮罩与勾选标记区分。Mac / 外接键盘支持 Cmd-A 全选与 Escape 退出选择。大图预览支持系统捏合缩放、双击缩放及放大后拖动。

照片选择和缩略图现在由可复用 UICollectionView 管理，图片请求在离屏或复用时取消，更新勾选不会重新请求图片。旧背景配置仍可解码，但不再改变活动页面背景。视觉检查与截图见 `.ui-checks/ux-polish/UX-REVIEW.md`。

### 2026-10-26 当天整理首页

启动默认进入“今天的画面”，按“随手拍”和“屏幕截图”展示当天可访问的图片。点分类可整理该类，底部“继续整理”会接着处理当天尚未判断的内容。日期入口用于回看往日；“全部照片”继续提供原生网格与批量选择，截图类型和月份筛选收进“筛选”菜单。已移除“继续上次整理”弹窗。

判断记录按设备保存，切换分类或日期、重新打开 App 都不会清空已整理状态；明确选择“重新整理当前范围”才会重置该范围。待删标记不受切换或重置影响，仍须手动确认系统删除。当天范围以设备当前时区的拍摄日期为准，日期未知的图片保留在“全部照片”中。有限权限下仅统计获准访问的图片。

选定设计为 `Design/selected-daily-inbox.png`。仅 Debug 的 `-dailyInboxFixture` 启动参数启用隔离的 UI 测试照片服务和 UserDefaults；常规启动仍使用真实 PhotoKit，Release 不包含该测试服务。

### 2026-10-26 日历数量与分组操作（构建 7）

日历在日期下显示当天可访问图片数，首页日期旁也显示总数。可切换月份或点击月份快速跳转日期。分组行右侧“更多”、左滑和长按提供重命名与删除；系统只读相册保留只读状态。删除分组保留照片库原图。

已精简首页、空状态、待删清单、画册与记录提示。App 自己的删除确认已移除，点击删除后直接执行；照片库写入仍遵循 PhotoKit 的系统确认。取消系统删除或操作失败会保留待删项，失败提示由当前页面呈现。

### 2026-10-26 待删入口与最近照片（构建 8）

首页标题下新增带数量的“待删”入口，全部照片上方也可直接打开清单；多选底栏用“待删”直接标记选中的图片，省去“更多”菜单。分组内选择照片后，“分组”菜单可添加或移出照片。整理页移除左右判断按钮和重复提醒，照片区域扩大；保留滑动、辅助功能操作、左右方向键、撤销与底部待删入口。

今天没有照片时显示最近 7 个自然日的照片与截图。如果图库更早，则以最近有照片的日期结束该 7 天范围；首页标明实际日期范围及数量。当天出现新图片后恢复今日照片；主动选择往日日期仍只展示那一天，日期未知图片仍可在全部照片查看。

可编辑分组提供“删除分组（保留照片）”和“删除分组及 N 张原图”。后者在同一次 PhotoKit 事务中删除分组内的图片原件与分组，图片在其他相册中的关联也会消失，梦想画册独立副本保留；不处理视频。系统拒绝、取消或失败时保留分组和照片。App 不追加确认弹窗，PhotoKit 的系统授权仍保留。有限授权下仅清理成功事务返回的资源标识，不用有限快照清空其他整理记录。

待删清单在系统删除成功后自动关闭并返回上一页；取消、失败或没有可删除项目时继续保留页面和待删状态。

整理完当前范围后自动回到照片首页，包括从全部照片、分组或“我的”进入的整理；待删标记和判断记录保留，不再停留在完成页。

全部照片中的大图预览支持左滑待删、右滑保留并进入下一张；放大时拖动只平移照片。分组与画册导入使用完整页面，加入分组支持收起键盘与滚动，避免窄屏裁切。


### 2026-10-26–27 首页进度与滑动体验（构建 9）

当前首页范围整理完后显示简洁的完成卡片，隐藏没有图片的分类；继续整理按日期接着处理更早、尚未判断的照片和截图，再处理日期未知的图片。已完成分类仍可点击浏览，全部照片提供明确的“重新整理”入口。

日期下保留数量，灰圈、橙色半圈、薄荷绿勾分别表示未整理、整理中和已整理，并同时提供图例与辅助功能文字。系统/只读分组用文字标记替代锁图标，点击可查看可操作范围；其中照片仍可整理和加入其他分组，结构修改按 PhotoKit 能力提供。

全部照片采用系统导航栏，标题居中，移除重复的照片标题；支持向右滑回首页。iOS 26 使用系统整页交互返回，旧系统保留边缘返回及整页滑动兼容。多选期间暂停返回手势，完成选择后恢复，避免横向连续选择误退出。大图跟随手指移动，短滑回弹、提交后滑出，最多预加载下一张预览；放大平移与左右判断继续区分。判断在松手时持久化，关闭页面也不会丢失刚才的操作。

### 2026-10-27 待整理首页与提醒（构建 11）

首页现在自动选择最近一个尚未整理完成的日期，只展示未整理的照片和截图。当天完成或没有图片时，跳过完成日期，继续往前找；有日期的图片都处理完后再显示日期未知图片。新拍的照片优先出现。首页采用紧凑的分类卡片、三张缩略图预览、右上角全部照片、日期与待删入口，以及沿用上一版的底部进度栏（圆环、状态、日期和右侧继续整理）。全部完成才显示空任务状态，不再展示已完成分类。

日期面板仍显示每天的全部数量与进度，新增“重新整理当天”。选择日期后点击会仅重置该日判断并进入整理，其他日期的进度和已有待删标记保留；普通切换日期不会重置进度。

“我的”新增独立的“整理提醒”，默认关闭，首次开启才请求通知权限；默认每天本地时间 22:00，可修改时间。关闭会取消该提醒；不影响已有梦想提醒。设置仅保存在当前设备，不进入画册 iCloud 备份。系统拒绝通知时提供通知设置入口，调度失败可以重试。更新提醒使用同一通知标识，避免重复累积，串行同步处理快速开关或修改时间。

全部照片的筛选改为独立面板：内容类型、月份和重新整理分区展示，支持重置筛选；月份使用原生列表选择，不再使用嵌套弹出菜单。

源码仓库为 https://github.com/luchuangao/DreamAlbum 。后续每次版本更新完成相关验证后提交并同步，规则记录在 AGENTS.md；编译缓存、签名材料、个人数据和本机原始测试产物不提交。


### 2026-10-28 日期任务首页（构建 12）
